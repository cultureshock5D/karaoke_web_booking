# ENCORE KTV — Standalone HTML Demo

This is a simplified, zero-dependency HTML/CSS/JS standalone demo of the **ENCORE Private KTV Rooms** website and booking flow.

## How to View
Double-click `index.html` in Windows Explorer or open it directly in any modern browser (Chrome, Edge, Safari, Firefox). No Node.js, server, or build step is required.

## What's Included
- **Dark Editorial Nightlife Design**: Space Grotesk headlines, Inter typography, `#111111` background, and `#e85c1a` electric orange accents.
- **Hero & Guarantees**: Giant watermark, guaranteed slot constraints, and high-resolution local photography.
- **Rooms Table**: Hover-raise room cards with capacity and hourly pricing.
- **Interactive Booking Modal**:
  - Room selection (Cozy Duo, VIP Galactic Suite, Mega Starlight Hall)
  - Duration selector (1h–4h) and start time selector
  - Add-ons (San Mig Beer buckets, snack platters) with live quantity steppers
  - Real-time receipt calculation (room subtotal, add-ons total, deposit due)
  - Instant simulated confirmation screen with booking reference code (`KTV-XXX-XXX`).
